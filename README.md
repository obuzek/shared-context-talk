# The Elements of Context Engineering

Olivia Buzek's keynote, JPMorgan Chase, October 22, 2026.

**View the slides: https://obuzek.github.io/shared-context-talk/**

Press `S` for speaker notes, `D` to toggle dark mode. Click or use the arrow keys to advance.

## Run locally

```sh
npm install
npm start   # http://localhost:8000
```

Slides are in `slides.md` (reveal.js markdown); diagrams are SVGs in `diagrams/`. Large binaries are stored with Git LFS.
